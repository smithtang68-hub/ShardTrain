# GPU 物理映射与 FSDP 通信链路

## 背景

逻辑布局和消息大小相同时，GPU映射仍可能改变通信耗时。对完整payload为M、group size为p的AG，可用 `t ≈ alpha + ((p-1)/p)*M/beta_eff` 描述启动成本与有效传输成本。该近似只给独立通信的方向预期，不把设备标称带宽直接代入训练kernel驻留时间。

本实验将FSDP两组链路从NV2改为PHB与NV1，而TP/SP的物理成员集合保持不变。因此预期新映射的独立FSDP通信更慢；如果这些通信暴露在训练关键路径上，完整step也应变慢。若被计算完全覆盖，则独立延迟变化未必带来相同比例的步时变化，不预先指定一个降速百分比。

先用相同消息和dtype的独立通信测试验证链路延迟，再用相同训练工作量验证完整step，并检查状态显存是否基本不变。三者一起区分“链路放置变差”与“模型工作量或容量改变”。

## 实验

**物理映射**

逻辑 mesh 始终为 `[[0,1],[2,3]]`，rank=f×2+t，FSDP 有序组为 02/13、TP/SP 为 01/23。物理 GPU 记作 A/B/C/D；M0 为 ABCD，M1 为 ABDC。

| 放置 | FSDP 物理 pair | TP/SP 物理 pair |
|---|---|---|
| M0_identity | AC NV2 / BD NV2 | AB NV1 / CD PHB |
| M1_swap23_tradeoff | AD PHB / BC NV1 | AB NV1 / DC PHB |

第二TP组的成员集合不变，但顺序反转。逻辑分片、初始参数、训练输入和运行策略保持匹配。模型日志显示，NV2/NV1轴使用GPU间直接访问，PHB轴使用共享主机内存路径。

**性能与显存**

本实验比较两种GPU物理映射，使用相同的训练实现和配置。完整随机 Qwen1.5B，四 V100、F2T2/SP、S512/MB4每F副本/A2、前后向参数预取及异步梯度归约均开启，主要 GEMM FP16、参数 AG/梯度 RS FP32。每组 3 个 fresh process、10 warmup+30 measured，profiler-off；每 step 使用四 rank 最大完整完成时间，8176 labels 不重复计 TP。

| 引擎 / 放置 | Mean ms | P50 / P95 ms | run mean SD ms | labels/s |
|---|---:|---:|---:|---:|
| ShardTrain / M0 | 1512.317 | 1505.253 / 1563.660 | 13.947 | 5406.27 |
| ShardTrain / M1 | 2660.513 | 2653.892 / 2679.369 | 14.100 | 3073.09 |
| Native matched / M0 | 1833.116 | 1817.449 / 1912.467 | 21.452 | 4460.16 |
| Native matched / M1 | 3161.993 | 3158.891 / 3184.333 | 8.448 | 2585.71 |

SD 以三个独立 run mean 计算，P50/P95 来自每组 90 个相关 step。同映射自研相对原生吞吐高 21.21%/18.85%。

| 引擎 / 放置 | peak allocated GiB | peak reserved GiB |
|---|---:|---:|
| ShardTrain / M0 | 13.81894 | 21.50195 |
| ShardTrain / M1 | 13.81040 | 21.22656 |
| Native / M0 | 15.42685 | 19.71094 |
| Native / M1 | 15.42685 | 19.71094 |

峰值取正式测量中所有rank、所有独立运行的最大值；reserved包含分配器缓存。NVML采样得到四组实验的最小空闲显存分别为9.456/9.779/11.316/11.352GiB。

**通信计量**

63次nccl-tests覆盖21个条件、每个条件3次独立运行，全部结果正确。93,601,792B的FP32 decoder参数AG平均耗时为：AC/BD两条NV2链路1.5438/1.5373ms，AD的PHB链路8.8039ms，BC的NV1链路2.9669ms。共享embedding/head的大消息测试也呈现相同方向，支持优先将FSDP通信放在两组NV2链路上。

两份时间线均观察到反向三路通信重叠，边界数为200/200。较慢映射的前向双AG重叠次数更多，同时也存在早到rank等待对端的现象。结果表明，通信重叠需要与合适的链路放置结合，网络拓扑对于通信效率影响显著。

## 结论

- **本机Hybrid应选择M0的两组NV2 FSDP链路。** swap23将其改为PHB＋NV1后，自研step从1512.317增至2660.513ms，增加75.92%；原生从1833.116增至3161.993ms，增加72.49%。
- **相同消息的独立测试直接显示了链路放置的代价。** 93,601,792B FP32参数AG在两条NV2上约1.54ms，在PHB上为8.80ms、NV1上为2.97ms；主要参数通信应优先映射到更快链路。
- **更多驻留重叠没有抵消慢链路。** M1前向双AG交集更多，完整step仍明显变长；两种映射的allocated峰值基本相同。完整step应作为物理映射选择的最终性能指标。
